\# Single GPU LLM Finetuning



Single-GPU QLoRA fine-tuning of Qwen2.5-7B-Instruct on the No Robots dataset using an RTX 3080 Ti.



\## Overview



This project explores parameter-efficient instruction fine-tuning of a 7B language model on consumer hardware. The goal is to build a portfolio-quality end-to-end LLM fine-tuning project, including training, inference, evaluation, and documentation.



\## Stack



\- Base model: Qwen2.5-7B-Instruct

\- Dataset: HuggingFaceH4/no\_robots

\- Method: QLoRA

\- Hardware: NVIDIA RTX 3080 Ti (12 GB VRAM)
